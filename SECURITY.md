# Security Policy

## Supported Versions

| Version | Supported |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and privacy of BahiKhata very seriously. BahiKhata operates as a 100% offline application storing data locally in browser/WebView IndexedDB.

If you discover a security vulnerability or potential data leak:
1. Please **do not** open a public GitHub issue.
2. Email your findings directly to the repository maintainer.
3. We will acknowledge receipt within 48 hours and work on a patch promptly.
