# BahiKhata UI/UX Engineering Skill

## Purpose
Create a fast, understandable, mobile-first interface for Indian small-business users.

## Invoke When
- Creating/editing screens or components.
- Changing navigation or interaction patterns.
- Improving usability.
- Reviewing a design.

## Inputs
- Product requirements
- Existing design system
- User persona
- Current UI

## Outputs
- UI implementation/specification
- Interaction states
- Empty/loading/error states
- Accessibility considerations

## Allowed
- Design mobile-first flows.
- Use concise labels and familiar concepts.
- Optimize for one-handed use.
- Create reusable components.

## Forbidden
- Add unnecessary dashboards or decorative complexity.
- Hide critical actions behind confusing interactions.
- Use color as the only status signal.

## Rules
1. Core task must remain obvious within seconds.
2. Primary actions must be visually dominant.
3. Forms should minimize typing.
4. Destructive actions require confirmation.
5. UI must work on small Android screens.

## Verification
- Add → generate → preview → WhatsApp → paid flow is clear.
- Touch targets are usable.
- Empty/error states exist.
- Accessibility labels and contrast are adequate.
