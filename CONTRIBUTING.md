# Contributing to BahiKhata

Thank you for considering contributing to BahiKhata!

---

## 1. Code of Conduct

Please read and abide by our [Code of Conduct](CODE_OF_CONDUCT.md) in all community interactions.

---

## 2. Development Workflow

1. Fork the repository and create a feature branch (`git checkout -b feature/amazing-feature`).
2. Install dependencies via `npm install`.
3. Ensure unit tests pass (`npx vitest run`).
4. Ensure the web build succeeds (`npm run build`).
5. Ensure Capacitor Android sync succeeds (`npx cap sync android`).
6. Commit your changes (`git commit -m 'feat: add amazing feature'`).
7. Push to the branch (`git push origin feature/amazing-feature`).
8. Open a Pull Request!
