## [1.0.0] - 2026-08-29

### Added
- **100% Offline IndexedDB Engine**: Device-local ledger storage with zero cloud dependencies.
- **Integer Paise Financial Calculator**: 0 rounding floating-point errors.
- **Multilingual Payment Reminders**: Prepared WhatsApp reminders in English, Hindi, and Bengali.
- **Dynamic Live Reminder Preview**: Real-time message text preview in settings and composer modals.
- **Independent Typography Scaling**: CSS variables (`--app-font-scale`) for font scaling without viewport distortion.
- **Outer Content Margin System**: Reusable `AppContentContainer` providing subtle 10px margins on mobile screens.
- **Complete App Settings Architecture**: Appearance, Reminder Settings, Preferences, Data & CSV, About, and Safe Settings Reset.
- **CSV Export & Import**: Ledger backup and restoration functionality.
- **TSV Bulk Add Sheet**: Spreadsheet modal for fast multi-customer creation.
- **Capacitor Native Android Container**: Packaged Android APK and AAB build setup.
